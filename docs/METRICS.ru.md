# Показатели

## Пропускная способность (Throughput)

Показывает, сколько операций структура выполняет в единицу времени:

$$
\text{Throughput} = \frac{N}{T} \quad [\text{ops/s}]
$$

где $N$ — число завершённых операций, $T$ — время измерения в секундах.

## Задержка (Latency)

Показывает, сколько времени занимает отдельная операция. Измеряется в наносекундах (нс).

| Метрика   | Значение                                                 |
|-----------|----------------------------------------------------------|
| Average   | средняя задержка                                         |
| p50       | медианная задержка                                       |
| p95       | 95-й перцентиль: 95% операций быстрее этого значения     |
| p99       | 99-й перцентиль: 99% операций быстрее этого значения     |
| p99.9     | 99.9-й перцентиль: 99.9% операций быстрее этого значения |

## Масштабируемость (Scalability)

Показывает, как ведёт себя тот или иной алгоритм при масштабировании на $N$ потоков. База — 1 поток:

$$
\text{Ускорение}(N) = \frac{T(1)}{T(N)}, \qquad
\text{Эффективность}(N) = \frac{\text{Ускорение}(N)}{N}
$$

Идеал — линейный рост; падение ниже 1 — отрицательное масштабирование (contention, false sharing).

## Потребление памяти (Memory usage)

Показывает, сколько памяти занимает структура: байт на элемент (накладные расходы) и пиковое потребление RSS.

## Загрузка процессора (CPU utilization)

Показывает долю времени, которую потоки проводят на процессоре.
